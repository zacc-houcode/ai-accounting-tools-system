    清单空的话，回到「工作流程建造器」，在需要检查的步骤上勾 Audit。

    📦

    导出整套体系

    把团队、全部流程和审计台整套导出成一个档案，交给 Claude Code，它照着建进你自己的电脑。以后加了流程或岗位，回来再导出一次就好。

    步骤一

    下载整套体系

    整套体系会存成一个 AI-SYSTEM-BUNDLE.md：团队 Plugin、每一条流程的 Plugin、Project 指令范本、安装核对清单和审计台。

    团队已经建好、只是多了几个岗位？按下面那颗就够。

    步骤二

    贴进 Claude Code

    在 Claude Code 里开一个空的新文件夹，把刚才下载的 AI-SYSTEM-BUNDLE.md 拖进对话框，按 Enter。它会先回一份计划，不会马上动手。

    它没有先给计划的话，补一句：

    建议用最新的 Fable 模型。看不懂它的计划就直接问它。

    步骤三

    装起来用

    确认计划 → 让它建 → 你会得到一个 ai-team/ 和每条流程一个 wf-…/。

    1. 装上团队 Plugin，再装要用的流程 Plugin。
    2. 为每个客户／期间开一个 Claude Project。
    3. 把 project-template 的指令贴进 Instructions，填上前三段（含审计台位置）。
    4. 照 INSTALL-CHECK.md 核对一次，特别是审计台打不打得开。

    同一支团队可以配所有流程。换客户开新 Project，Plugin 照装。
